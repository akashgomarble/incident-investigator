# Incident investigation report: INC-011
*System: multi_agent | outcome: **root_cause_identified** | ended: critic_accepted*

## Summary
Root cause identified with high confidence (0.78): the pricing-engine config change cfg-3120, which at 2026-05-20T12:04:00Z ramped flags.pricing.greeks_v2.rollout_pct from 5 to 100, moved all quote traffic onto the CPU-bound GreeksV2Calculator Monte-Carlo path (~20k paths, 2.9-8.7s per quote). pricing-engine CPU stepped from ~39-41% to ~99% and held, request_rate stayed flat, its own error_rate stepped to ~13%, and p99 went 60ms -> ~2600ms, so order-service quote calls exceeded their 2500ms budget and returned 8% 5xx. The alternative single-change candidate, the market-data-service protobuf deploy dep-6111 at 11:56Z, is outside the onset window and its broader consumer footprint (MDS, api-gateway, portfolio-service) shows no anomaly. Shared redis-cache degradation was ruled out as the mechanism because a blocked-on-cache wait would predict flat CPU rather than the observed load-independent CPU saturation and in-process Monte-Carlo error logs. Residual uncertainty is limited to the flag's runtime effect and 120s telemetry resolution.

## Probable root cause
**pricing-engine Greeks v2 flag ramp (cfg-3120) puts an expensive Monte-Carlo path on all traffic, saturating CPU and stalling quotes** -- config_change in `pricing-engine`, triggered by `cfg-3120` (confidence 0.78, high)
